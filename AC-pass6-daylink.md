# AC — NightDeck Pass 6 (day link + live board)

## Hard stops
1. **Light theme:** white/blue UI; not dark-first.
2. **Create day:** host chooses Trivia OR Identify OR Music once, enters name → gets permanent day URL (code in link).
3. **Join day:** opening that URL → name entry → play that fixed game type (no choose-round-type screen).
4. **Live leaderboard:** as players finish, scores appear on a shared board for that day (Upstash); board refreshes without reload spam (poll OK).
5. **No blank-fill** remains.

## Must-holds
- Workplace-clean content; mobile-usable; solo demo path if cheap
- Day link works on phones (multi-device via Upstash)

## Out of scope
- Multi-type mix nights; Neon; Worker proxy
