# AC — NightDeck Staff Night (trivia / identify / music)

## Hard stops
1. **Lobby:** Host creates room, players join with code; supports ≥12 seats; start with ≥2 humans (or solo demo).
2. **Trivia round:** Host starts a trivia question (4 options); players lock an answer; host reveals correct; scores update.
3. **Identify round:** Host shows an identify prompt; players submit a guess (or pick options); host marks correct / reveal; scores update.
4. **Music round:** Host shows a lyric/line cue; players guess song/artist; host reveals; scores update.
5. **Night flow:** Host can run many short rounds in any mix; scoreboard visible; host can end night → shareable podium.
6. **No blank-fill card game** remains as the primary experience.

## Must-holds
- Clean workplace humor/content
- Human, friendly UI voice
- Solo demo path for host testing
- Mobile-usable

## Out of scope
- Real audio streaming of commercial tracks
- Cloud sync
- Spicy packs
