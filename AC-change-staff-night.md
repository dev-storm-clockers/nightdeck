Prior hard stops still stand. This delta adds staff-night requirements.

## Hard stops (staff-night)

1. **Clean default:** New/staff sessions default to **Lobby Warmup** workplace-clean only; **Group Chat Unhinged** is gated or hidden (not the default deck).
2. **12 seats:** Lobby can seat **~12** players (host + joiners up to that cap); start still respects multi-human min (≥3 real) except in solo demo.
3. **Short rounds:** Submit/play phase is short (fast to play a card); round does not stall waiting on slow submit beyond the short window.
4. **Long judge window:** Judge has a clearly longer window to pick the winner (async-friendly / step-away); winner can still be chosen after others have submitted.

## Must-holds

- Solo demo + visual refresh AC still apply.
- ~5h hang time = many short rounds over a long session (no forced session timeout that kills a staff night early) — or document TTL only if it won’t break a 5h hang.
- Spelling **NightDeck**; no spicy deck as staff default.
